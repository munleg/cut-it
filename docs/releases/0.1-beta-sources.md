# Cut-it 0.1 Beta: corresponding source

The Windows download is accompanied by the following source materials at no charge.

- **Cut-it, CuteLogger, launcher, and modifications:** [release source](https://github.com/munleg/cut-it/tree/v0.1.0-beta.1), including build and packaging scripts. The release also supplies Cut-it-source.zip.
- **Bundled libraries and plugins:** exact source packages below, hosted on the official MSYS2 mirror. These source packages include the package build recipes and source inputs.
- **Fonts:** bundled fonts and OFL notices are in the fonts directory.
- **Binary provenance:** [dependency manifest](0.1-beta-dependencies.json) records each shipped binary hash and the locally verified owning package/version.

All source URLs were checked on 2026-10-16. There are 123 binary packages from 120 distinct source archives (about 1.32 GiB total). These are optional downloads for rebuilding, not needed to run Cut-it. If a source link stops working, report it in this repository so release maintainers can restore equivalent access.

## Build information

Use Build-CutIt.ps1 and the retained upstream README-SHOTCUT.md for the application. The bundled dependencies are unmodified MSYS2 MinGW64 package binaries: use the exact source archive and its PKGBUILD for each version. The dependency bundler is packaging/bundle-dependencies.py; the Windows launcher is packaging/launcher.cpp, and the installer definition is packaging/Cut-it.nsi. The application uses dynamic DLLs; retain their notices and license files.
