# Cut-it 0.1.2

This update adds preview pose keyframes using the existing Shotcut/MLT animation engine.

- Small diamond below the preview saves position, size and rotation together. Select a clip, save its starting pose, move the playhead and adjust its transform, then save the next pose. Changing a transform at a new time also updates its keyframe.
- Filled diamond indicates a position/size keyframe; adjacent arrows navigate those points.
- Repeated diamond clicks save the pose instead of deleting it. Right-click opens the full Keyframes editor.
- Text transform handles remain active while seeking. Text also has an Animate text entry point.
- Keyframes and Timeline can remain visible together.

Validation: native Windows release build and seven regression tests passed; live checks verified saved poses, midpoint interpolation, and project Undo/Redo. Existing simple in/out animations are preserved and require the full editor. GPU Size & Position supports position/size but not rotation. Full export, every preview drag/rotation gesture, and installation on another PC were not comprehensively retested.
