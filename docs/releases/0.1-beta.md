# Cut-it 0.1 Beta

First beta checkpoint for the simplified Windows editing workspace.

## Included
- Monochrome workspace with persistent preview and timeline.
- Text layers with quick styles, font selection, and optional Google Fonts downloads.
- Searchable effects cards and guided color-adjustment entry points.
- Ctrl+B split and Backspace/Delete gap-closing deletion; customizable shortcuts.
- Waveform/thumbnail work scheduling and font-registration fixes from the alpha.

## Validation and limits
The native Windows build passed. The preceding interface checkpoint passed all five native regression tests and live checks for text creation/style changes, color entry/Brightness, and the effects gallery. The Beta designation does not imply comprehensive stability or hardware certification. Advanced color controls still use the original Shotcut panels.

## Release assets
The local Windows installer is named `Cut-it-0.1-Beta-Setup.exe`. The release supplies Cut-it-source.zip and SHA256SUMS.txt. Matching dependency source archives and build information are linked in [0.1-beta-sources.md](0.1-beta-sources.md); their versions and bundled binary hashes are recorded in 0.1-beta-dependencies.json.
