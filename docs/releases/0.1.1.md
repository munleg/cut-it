# Cut-it 0.1.1

Windows update with the temporary Cut-it logo, Silence Removal, and GitHub update checking.

- Select a clip and press **Ctrl+Alt+V** for Silence Removal. Adjust threshold, minimum duration, and the total retained gap (0.1s, 0.2s, etc.). Gap adjustments reuse the audio scan.
- Review detected pauses, delete selected ranges with **Ctrl+Enter**, and restore the operation with **Ctrl+Z**. Cuts use video-frame boundaries and ripple only the selected track. Other tracks remain unchanged.
- Check GitHub Releases on startup, or use **Help > Check for updates**. Updates open the download page; save and close Cut-it before installing.
- Updated app, launcher, and installer icons. Text, effects, and color improvements from the previous development builds are included.

## Downloads and source

Install `Cut-it-0.1.1-Setup.exe`. This updates the existing per-user installation. The installer is unsigned.

Matching application source is in `Cut-it-0.1.1-source.zip`; verify downloads with `SHA256SUMS.txt`. Bundled third-party binaries are unchanged from Beta 1: their exact versions, hashes, and corresponding source archive links are recorded in the [dependency source guide](https://github.com/munleg/cut-it/blob/v0.1.1/docs/releases/0.1.1-sources.md) and [manifest](https://github.com/munleg/cut-it/blob/v0.1.1/docs/releases/0.1-beta-dependencies.json).

## Validation and limitations

Native Windows build and seven regression tests passed before packaging. Silence tests cover frame rounding and retained gaps, with earlier generated-audio detection checks. Interactive silence deletion/Undo on real projects and installation on a second PC remain unverified. Source-audio silence detection excludes timeline audio filters, speed-adjusted clips, and transitions. Review quiet speech before deleting.

Cut-it remains an early development editor. This version number is not a claim of production readiness. GPL licensing, Shotcut attribution, and dependency/font notices are preserved.
